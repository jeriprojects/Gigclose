# GigsClose Flutter App

This Flutter project is now a native client for GigsClose, not a webview shell.

It connects directly to the same Supabase backend used by the website and includes:

- native home screen aligned with the website brand
- native explore flow with exact-word search and category grouping
- native account auth and dashboard screens
- native job detail and apply flow

Build a release APK with:

```bash
flutter build apk --release
```
